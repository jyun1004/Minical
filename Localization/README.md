# Pending translations

Minical ships in English only for now. Korean translations written so far are kept in
`ko-pending.json` (keyed by catalog, then by string key, in String Catalog `localizations` format)
so they can be merged back into `Minical/Resources/*.xcstrings` once the English UI is final.
Add `ko` back to `CFBundleLocalizations` in `project.yml` at the same time.
